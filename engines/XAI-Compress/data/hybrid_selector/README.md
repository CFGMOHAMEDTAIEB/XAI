# Hybrid Selector V2 corpus

`corpus_manifest.csv` is generated by `scripts/build_hybrid_v2_corpus.py`.
Real files remain at their original workspace paths and are never modified.
The `synthetic/` directory contains deterministic controlled size/category
examples used in addition to, not instead of, the real-file corpus.

Splits are assigned by source group, so data derived from one original file
cannot cross train, validation, and test boundaries.
